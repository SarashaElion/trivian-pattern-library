## Purpose

The Trivian Pattern Library is the small-pattern layer of the personal ecosystem: developers who already have an AI system can adopt one relational pattern without installing TRIA or reproducing the full research stack.

## Implemented patterns

- Reciprocity: attentional symmetry proxy;
- Embodiment / situatedness: context-grounding presence check;
- Emergence: optionality-preservation check;
- Non-Domination: declared consent/reversibility gate;
- Rupture / Repair: minimal repair-sequence state machine.

Each pattern is intentionally small, standard-library-only, typed, documented, and tested.

## Epistemic scope

These patterns are implementation primitives, not validated psychological, moral, clinical, or consciousness measures. Each module states what it directly observes and what it does not establish.

## Relationship to TRIA

This repository is not a replacement for TRIA. It is a developer cookbook / pattern catalog for selectively incorporating Trivian relational design ideas into an existing system.
